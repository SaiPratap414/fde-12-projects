# Customer Onboarding Automation

Self-serve setup flows, guided checklists, in-app docs, and time-to-first-value tracking.

**Shows:** You reduce support burden through product thinking.

## Core ideas
- **Guided checklist** that tracks onboarding steps per customer.
- **Time-to-first-value (TTFV)** measured from signup to first key action.
- **Self-serve** flows so customers don't need support to start.

## Structure
```
src/
  checklist.ts   # onboarding steps + completion tracking
  ttfv.ts        # time-to-first-value measurement
```
